# 自動記帳收件匣（iPhone 捷徑）

收件匣是「記帳專用的信箱」：iPhone 的捷徑 App 在你付款或收到通知時，自動把內容寄到你自己的伺服器；打開 Aster 確認一下就記好帳。

```
Apple Pay 付款／銀行簡訊／對 Siri 說一句話
        │  iPhone 捷徑（自動化）
        ▼
POST https://你的網址/api/hook/inbox   ← 捷徑專用權杖（只能寄、不能讀帳）
        │  伺服器暫存
        ▼
打開 Aster → 解析成帳目 → 確認記帳（或自動入帳）→ 從伺服器刪除
```

## 1. 一鍵加入捷徑（建議）

App →「設定 → 自動記帳收件匣」→「加入 iPhone 捷徑」，**六個**捷徑都已經做好並經 Apple 簽署；畫面是一個**安裝精靈**：按「依序加入」→ 在「捷徑」App 加入 → 回到 Aster 自動打勾並提示下一個，Apple Pay／簡訊加入後還會用清單帶你做完「建立自動化」那一步（iPhone 不允許 App 代設）。

| 捷徑 | 用途 | 加入後還要做 |
|---|---|---|
| Aster 記一筆 | 說「嘿 Siri，Aster 記一筆」→ 說一句話（可多筆） | 不用（想說「記一筆」就把捷徑改名） |
| Aster 快速記帳 | 點一下跳出輸入框，打「午餐 120」（來源 `quick`） | 可綁到動作按鈕、背面輕點、主畫面 |
| Aster 貼上記帳 | 把剪貼簿的文字（從銀行 App、LINE 複製的交易明細）送進來（來源 `clipboard`） | 不用 |
| Aster 分享記帳 | 出現在任何 App 的分享選單（來源 `share`） | 第一次到分享選單的「編輯動作」加進常用 |
| Aster Apple Pay 記帳 | Apple Pay 付款後送出金額、商家、卡片 | 建立「交易」自動化 |
| Aster 簡訊記帳 | 銀行刷卡簡訊送出整則內容 | 建立「訊息」自動化 |

步驟：

1. 按「**加入**」：App 自動建立權杖、把**連結碼**（`https://你的網址/api/hook/inbox?t=clr_…`）複製到剪貼簿，並直接切換到「捷徑」App 的匯入畫面（需要 HTTPS 網址；匯入完按左上角「◀ Aster」回到 App）
2. 按「**設定捷徑**」，長按輸入框 →「**貼上**」
3. 按「**加入捷徑**」，名稱可以自己改

同一台裝置加第二、第三個捷徑時會重用同一組連結碼。連結碼外洩時按「重新產生連結碼」，舊的捷徑會失效、需重新加入。

**自動化（Apple Pay／簡訊）**：iPhone 不允許 App 代為建立自動化，需要自己做一次（在 iOS 26 實機走過）：

1. 「捷徑」App →「資料庫」頁點「**自動化**」→ 最下方「**＋**」（iOS 17～18：「自動化」是下方分頁，點「＋」後選「新增個人自動化」）。
2. 點上方「**自動化操作**」標籤，往下捲：
   - **Apple Pay**：在「App」區點「**錢包**」（說明「在我感應『錢包』卡片或票卡時」）。**沒有叫「交易」的選項**——iOS 26 把「交易」改名成「錢包」（iOS 17～18 才叫「交易」）。出現「感應 任何卡片 時」＝每張卡都記，不用改；想限定某張卡就點「任何卡片」。
   - **簡訊**：在「通訊」區點「**訊息**」。這個觸發**一定要填條件**才能啟用：「寄件人 是」選銀行；「加入過濾條件」→「訊息 包含」填「消費」。
3. 點最下方搜尋框輸入「執行捷徑」→ 點藍字「捷徑」→ 選「Aster Apple Pay 記帳」或「Aster 簡訊記帳」。
4. 左上角「＜」存檔；「自動化」清單這一列的開關是綠色就啟用了。

**沒有跳到「捷徑」App**：請用 iPhone 開啟頁面；也可以按「沒有跳到捷徑 App？」裡的連結下載，再到「檔案」App 的「下載項目」點開。本機 HTTP 測試時「捷徑」App 不接受網址匯入，「加入」會改為下載檔案。若「設定捷徑」畫面卡住，可先按「略過設定」加入，再打開捷徑，把第一個「文字」動作的內容換成連結碼。

> 捷徑檔放在 `public/shortcuts/aster-*.shortcut`（共 6 個；`--only quick,share` 只重做指定的）（檔名用英文，匯入後的中文名稱由 App 帶入），由 `python3 scripts/make-shortcuts.py` 產生並簽署（需要 macOS 與 Apple ID）。檔案裡沒有任何網址或權杖，每位使用者共用。
> NAS 外層有登入保護（Cloudflare Access 等）時，需放行 `/shortcuts/` 與 `/api/hook/`。

## 2. 進階：自己動手建立捷徑

想修改捷徑內容，或用在其他自動化工具時，在「進階：自己動手建立捷徑」建立一組權杖。畫面會顯示：

| 項目 | 內容 |
|---|---|
| 網址 | `https://你的網址/api/hook/inbox` |
| 標頭值 | `Bearer clr_…`（只顯示這一次，請直接複製到捷徑） |

可以按「傳送測試項目」確認連得到。權杖遺失或手機換掉時，撤銷舊的再建一組即可。

共同動作都是「**取得 URL 的內容**」：

- 網址：上面的網址（或直接用連結碼，就不用設標頭）
- 方法：`POST`
- 標頭：`Authorization` ＝ 標頭值（`Bearer clr_…`）
- 要求本文：`JSON`，欄位類型都選「文字」

| 捷徑 | 欄位 |
|---|---|
| Apple Pay（「交易」自動化） | `source`＝`applepay`、`amount`＝捷徑輸入 → 金額、`merchant`＝捷徑輸入 → 商家、`card`＝捷徑輸入 → 卡片或票證 |
| 簡訊（「訊息」自動化） | `source`＝`sms`、`text`＝捷徑輸入 → 內容 |
| Siri（「聽寫文字」中文（台灣）） | `source`＝`siri`、`text`＝聽寫的文字 |

## 3. App 怎麼判斷

- **金額**：Apple Pay 的金額欄位；簡訊找「NT$」「元」後面的數字（不會把卡號末四碼當金額）
- **日期**：簡訊或 Siri 內容裡的日期（10/27、昨天）；沒有就用收到的時間
- **帳戶**：學過的「卡片 → 帳戶」→ 文字裡的帳戶名稱 → 自動分類規則指定的帳戶 → 同一個商家最常用的帳戶 → 收件匣預設帳戶
- **分類**：自動分類規則 → 商家記憶 → 文字裡的分類名稱 →「其他」
- 確認記帳時會記住「這張卡 → 這個帳戶」，可在收件匣頁面修改

## 3.5 重複的項目

同一次消費常常有好幾個來源（Apple Pay 通知、銀行簡訊、電子發票載具、手動記帳）。收件匣會比對「同金額、同幣別、日期相差 1 天內」的帳目：

- **很可能重複**（同一天，且商家相近或同一帳戶）：顯示「⚠️ 很可能重複」，按「合併（不重複記）」只補上缺少的商家、不新增帳目；真的是另一筆（例如連買兩杯一樣的咖啡）按「仍要記帳」
- **金額相同**（差一天或商家不同）：只顯示「ℹ️ 金額相同」提醒，照常可以記帳
- 開啟「看得懂的直接記帳」時，很可能重複的不會自動記，留在收件匣等你確認；Apple Pay 與簡訊在 15 分鐘內通知同一筆付款，會自動合併
- 「全部記帳」不含很可能重複的項目

## 4. 安全與隱私

- 權杖只能「寄」，不能讀取任何帳目；伺服器只存 SHA-256 雜湊，可隨時撤銷
- 權杖可以放在 `Authorization: Bearer`、`X-Aster-Token` 標頭（舊名 `X-Clure-Token` 仍可用），或網址的 `?t=`（連結碼）；nginx 不記錄 `/api/hook/` 的存取日誌（1.3.1 起，需重新啟動 web 容器套用），API 也不記錄查詢字串；連結碼外洩就重新產生
- `/api/hook/inbox` 不使用登入 Cookie，所以不需要 CSRF；每組權杖每分鐘最多 30 則，錯誤權杖以 IP 限制
- 暫存內容**沒有端對端加密**（捷徑沒有你的加密密碼）；確認或略過後立即刪除，30 天未處理自動清除
- 兩台裝置同時確認同一則，只有一台會記帳

## 5. 常見問題

- **外出時捷徑失敗**：網址要用 NAS 的外部 HTTPS 網址；外層有 Cloudflare Access 等登入保護時，需放行 `/api/hook/`
- **Apple Pay 沒觸發**：iOS 17 以上才有 Apple Pay 自動化（iOS 26 叫「錢包」、iOS 17～18 叫「交易」）；部分卡片、交通卡不會觸發
- **送來空白或被拒絕的交易**：預設先放收件匣等你確認，可以按「略過」；確定都正確後再開「看得懂的直接記帳」
- **銀行改用 App 推播**：iPhone 無法讀取其他 App 的推播，只能用簡訊或 Apple Pay

## 預計扣款（本機推算）

收件匣最上面的「預計扣款」不經過伺服器：App 從你的記帳紀錄找出連續幾期金額差不多的固定扣款（訂閱、房租、保費…），**預計扣款日到了**就列出來；另外也列出設成「到期要確認」的週期帳目已到期的期數。

- 每月用同一天推算、每年同月同日、每週 +7 天；週 3／月 10／年 14 天內沒記就不再提示。
- 「記帳」：日期是預計扣款日、金額沿用上次（可復原）；「編輯」：帶進記帳面板改金額；「登記成週期」：之後每期到了固定提醒確認；「略過」：只略過這一次。
- 手動記過同一筆，預測自動消失。要關掉：收件匣頁「記帳方式 → 預計扣款提醒」。
