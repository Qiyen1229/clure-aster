# 已知限制與替代方案

## iOS PWA 平台限制
| 限制 | 影響 | 本 App 的做法 |
|---|---|---|
| PWA 無法在背景執行排程 | 不能在關閉時自動更新股價、入帳週期帳目 | **開啟 App 時補算**：週期帳目、分期、預算、匯率、股價、每日快照（缺漏日期自動補齊）、提醒檢查；回到前景時再檢查一次（10 分鐘節流） |
| 背景推播 | App 關閉時的提醒 | 啟用帳號系統時可開「背景推播」：App 開啟時排好接下來 14 天的提醒（每日記帳、繳款、續約、心願、備份），由自架伺服器到點送出。預算與到價提醒需要即時資料，仍只在 App 開啟時檢查。iPhone 需 iOS 16.4+、加入主畫面、HTTPS |
| 系統通知需 iOS 16.4+ 且加入主畫面 | Safari 分頁中無法通知 | 設定頁提供引導；不支援時自動降級為提醒中心 |
| 主畫面 App 與 Safari 分頁儲存空間分開 | 兩邊資料不同步 | 文件與引導提醒固定使用主畫面 App；跨裝置用 JSON 備份／還原 |
| 系統可能清除長期未使用的網站資料 | 資料遺失風險 | 啟動時要求 `navigator.storage.persist()`；備份提醒；健康檢查顯示持久化狀態 |
| manifest `shortcuts` iOS 不支援 | 長按主畫面圖示沒有快捷選單 | 用「捷徑」App＋深層連結 `/add?...`（Android／桌面 Chrome 支援 manifest shortcuts） |
| 語音辨識 | iOS standalone 模式部分版本不提供 Web Speech API | 不支援時隱藏麥克風按鈕；一句話記帳可改用鍵盤上的聽寫，或用 Siri 捷徑送到收件匣 |
| 無法讀取 Apple 錢包、簡訊、銀行 App 推播 | 不能直接自動記帳 | 用 iPhone 捷徑的「交易」「訊息」自動化把內容送進收件匣；銀行 App 推播 iOS 無法讀取 |
| Service Worker、通知、推播、Face ID 需 HTTPS | `http://NAS-IP:9122` 沒有離線、通知、推播、生物辨識 | 請用反向代理提供 HTTPS |

## 資料與安全
- 資料以明文存在瀏覽器 IndexedDB；App 鎖保護的是畫面，不是加密。請搭配裝置本身的密碼鎖。PIN 連錯 5 次起需等待（30 秒起倍增，最長 1 小時），重新整理也不會歸零。
- 忘記 PIN 只能清除網站資料；啟用同步時重新登入即可從伺服器取回資料。
- **跨裝置同步**：帳目會同步到你自架的伺服器。未啟用「端對端加密」時，伺服器資料庫中的帳目是明文 JSON（NAS 管理員或拿到資料庫檔的人可讀）；啟用後伺服器只保存加密後的內容，但資料表名稱、資料 id、修改時間仍可見。
- 端對端加密的密碼遺失無法復原伺服器上的資料（已解鎖的裝置仍保有明文）。
- 背景推播的通知文字會經過伺服器與瀏覽器推播服務（Apple／Google／Mozilla）；啟用端對端加密時推播不含金額與名稱。

## 報價資料源
- 所有免費資料源都可能延遲、限流或變更格式；介面已標示「報價可能延遲，僅供參考，不構成投資建議」。
- **Yahoo Finance（非官方）** 對部分網路（含部分雲端／家用 IP）會回 429。代理已加入 cookie 處理，但仍可能失敗；美股建議填入免費的 Finnhub／Twelve Data Key 作為備援。台股走證交所、櫃買、FinMind，不受影響。
- **mis.twse.com.tw** 對頻繁請求會暫時封鎖：前端每 1.5 秒最多一次，代理快取 10 秒。
- **興櫃**即時報價沒有穩定的免費來源：可搜尋與記錄交易，價格請依 FinMind／Yahoo 或手動輸入。
- **港股**僅透過 Yahoo，可能較不穩定。
- 台股休市日：開啟 App 時從證交所 OpenAPI 取得最新行事曆（快取 7 天）；離線或取得失敗時使用內建清單（`TW_HOLIDAYS`）。美股假日以規則計算。
- 個股走勢 1D／1W 依賴 Yahoo；失敗時台股改用 FinMind 日線，離線時使用快取的日線。

## 計算
- 所有金額以整數最小單位儲存；股價、股數、匯率以 decimal 字串計算，不使用浮點數。
- 台股手續費依「成交金額 × 費率 × 折扣，無條件捨去、最低 20 元（零股 1 元）」計算，實際以券商對帳單為準；可在交易中手改。
- 配股不足一股的部分不計入股數（通常以現金發放，請另記現金股利）。
- 外幣帳目的「主幣別金額」以記帳當下匯率保存；變更主幣別後請到「資料健康檢查」重算。
- 淨資產歷史：有每日快照的日期使用快照；更早的月份由帳目倒推帳戶餘額（以目前匯率換算），投資市值只能取當時快照。
- XIRR 需要至少一筆投入與一筆取回（含目前市值），且現金流不能全部在同一天。

## 其他
- PDF 報表採「瀏覽器列印 → 儲存為 PDF」，以獲得完整中文字型與小體積；不另外內嵌 PDF 函式庫。
- Excel 匯出使用內建的精簡 XLSX 產生器（無公式、樣式精簡）。
- CSV 匯入日期為 `03/04/2024` 這類前兩段都 ≤ 12 的格式時無法分辨月／日，一律依美式 MM/DD/YYYY；第一段 > 12 時自動判定為 DD/MM/YYYY。
- 編輯舊的「餘額調整」時，調整後餘額以「目前餘額」為準（基準＝目前餘額 − 原差額），也就是把帳戶目前餘額設為輸入值。
- 多語系：目前只提供繁體中文介面。3.6.5 起已移除未使用的 i18next 依賴（全 App 文字直接寫在程式裡，做完整雙語要逐處抽出，風險高，列為路線圖而非半套支援）。
- 收據照片只存本機（IndexedDB），不隨帳目同步到 NAS；**JSON 完整備份已包含全部照片**，換手機時用備份還原即可。選用同步到 NAS（含端對端加密）列為路線圖。
- 電子發票：
  - 手機條碼自動記帳需要財政部電子發票應用 API 的 AppID。財政部自 112 年 3 月 31 日起只受理通過 ISO 27001 等資安認證的企業或組織申請，個人自架通常無法取得；沒有 AppID 時請用 QR Code 掃描或匯入載具消費明細 CSV
  - 財政部 API 只能查最近約 9 個月的發票；發票上傳到載具最慢約 48 小時，因此每次會往前多查 3 天
  - 手機條碼驗證碼存在設定中並會同步（啟用端對端加密時加密）；查詢時會經過自架伺服器轉送給財政部，伺服器不保存
  - 紙本發票只讀左側 QR Code（右側只有品名延續）；載具 CSV 依財政部平台匯出格式解析，若官方改格式需更新 `src/services/einvoice.ts`
- 稅務彙總為估算：級距與免稅額採 113 年度標準，未考慮扶養、特別扣除額細節；海外所得的國外已繳稅額扣抵以簡化方式計算。
- 財務自由試算採常態分布的年報酬與固定通膨，未模擬報酬序列相關性與稅負。

## 帳號系統
- 帳目在各裝置的 IndexedDB 與自架伺服器之間同步，見 [SYNC.md](SYNC.md)。
- 登入頻率限制與帳號鎖定都使用資料庫計數，API 重啟或多個 worker 時仍有效。
- NAS 版的報價代理 `/proxy/` 只允許已登入的使用者（nginx `auth_request` → `/api/auth/check`）；關閉帳號系統（`VITE_AUTH_MODE=off`）時請在 `.env` 設定 `CLURE_PROXY_REQUIRE_LOGIN=false`。
- 「第一位註冊者成為管理員」只在系統沒有任何使用者時生效；對外開放前請先用環境變數或 CLI 建立管理員，並把 `CLURE_FIRST_USER_ADMIN` 設為 `false`。
- 離線模式只允許「曾在這台裝置登入過」的帳號；凍結或強制登出在裝置恢復連線並重新驗證時才會生效。
- 前端 `/admin` 路由守衛只是介面體驗，真正的權限檢查在後端（`require_admin`）。
- 管理員重設密碼產生的臨時密碼只顯示一次，不記錄在任何日誌或資料庫明文中。
- 審計日誌目前不自動清除；量大時可依 `created_at` 定期歸檔。
- 未設定 HTTPS 時 Cookie 不會帶 Secure 屬性（`CLURE_COOKIE_SECURE=auto`），只適合在可信任的區域網路使用。
- 自動記帳收件匣：
  - 捷徑送來的內容暫存在伺服器上，**沒有端對端加密**（捷徑沒有你的加密密碼）；確認或略過後立即刪除，30 天沒處理自動清除
  - 捷徑網址必須在 iPhone 上連得到（外出時要用 NAS 的外部 HTTPS 網址）；若外層有 Cloudflare Access 等登入保護，需放行 `/api/hook/`
  - Apple Pay「交易」自動化需要 iOS 17 以上；部分卡片、交通卡可能不觸發，偶爾會送來空白金額或被拒絕的交易，所以預設先放收件匣等你確認
  - 簡訊解析依「NT$」「元」與「商店：」等字樣判斷，各銀行格式不同，看不懂的會標示「請手動記」
- 現金流預測：日常花費以近 90 天平均估算；卡費、貸款沒有設定扣款帳戶時假設從餘額最多的同幣別帳戶扣；只計算已知的週期帳目、分期與貸款
- 一句話記帳、用問的查帳：以規則解析中文，不經過任何 AI 服務；說法差太多時可能判斷錯，帶入後仍可在記帳面板修改
